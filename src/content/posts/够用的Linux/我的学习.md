最近学习了大佬的 [《只学够用的 Linux：零基础最小入门教程》](https://www.zouht.com/4399.html)，把需要反复查阅的内容整理在这里。教程从命令行基础讲到服务器上的常用操作，我给自己的学习目标是：能找到文件、读懂命令、运行程序，遇到问题时知道从哪里查起。

下面以 **Ubuntu 和 Bash** 为例，按使用场景整理，并补充自己的练习示例。`apt` 属于 Debian / Ubuntu 系列的包管理工具，其他发行版需要换成对应的工具；命令示例应在 Linux 终端中执行。

## 一、先分清 Linux、发行版和 Shell

Linux 是内核；Ubuntu 等发行版把内核、系统工具、软件仓库等组合成可使用的系统。终端提供输入输出界面，Shell 负责解释命令。之前学过的 CMD、PowerShell 也是 Shell，下面记录的则是 Bash 的语法。

常见命令可以先按这个结构阅读：

```bash
ls -lah ~/Documents
```

这里 `ls` 是命令名，`-lah` 是组合的短选项，`~/Documents` 是操作对象。参数区分大小写，具体规则以命令自己的帮助为准。

```bash
ls --help     # 查询常用选项
man ls        # 阅读手册，按 q 退出
```

输入命令时多用 `Tab` 补全、上下方向键找历史记录。`Ctrl + C` 通常中断前台程序，`Ctrl + L` 清屏。

## 二、文件操作前，先确认自己在哪

Linux 的目录从 `/` 开始，路径使用正斜杠，文件名通常区分大小写。以 `/` 开头的是绝对路径，其余路径通常相对于当前工作目录；`.` 表示当前目录，`..` 表示上一级，`~` 在 Bash 中可展开为家目录。

```bash
pwd                    # 当前工作目录的绝对路径
ls -lah                # 包含隐藏项的详细列表，大小使用易读单位
cd ~/Documents         # 进入家目录中的 Documents
cd ..                  # 回到上一级
cd -                   # 返回上一次所在目录
cd                     # 回到家目录
```

以 `.` 开头的文件或目录通常隐藏，例如 `.bashrc`。`ll` 在一些环境里是 `ls` 的别名，换一台机器后未必存在。

| 常见位置 | 主要用途 |
| --- | --- |
| `/home/用户名` | 普通用户的家目录 |
| `/root` | root 用户的家目录，与根目录 `/` 不同 |
| `/etc` | 系统和服务的配置 |
| `/var/log` | 常见日志文件 |
| `/tmp` | 临时文件，不能当作长期存储位置 |
| `/usr`、`/opt` | 软件、库及附加应用的常见存放位置 |
| `/dev`、`/proc` | 设备入口以及内核、进程信息接口 |
| `/mnt`、`/media` | 常见挂载位置 |

## 三、新建、复制、移动和删除

下面这组练习在一个新建的目录里执行：

```bash
mkdir ~/linux-practice
cd ~/linux-practice
mkdir -p notes backup
touch notes/day1.txt
cp -i notes/day1.txt backup/day1.txt
mv -i notes/day1.txt notes/linux.txt
```

`mkdir -p` 可以补齐缺少的父目录；`touch` 对不存在的文件创建空文件，对已有文件主要是更新时间戳。`cp` 复制文件，复制目录常用 `cp -r`；`mv` 同时承担移动和重命名。目标路径是否已经存在，会影响最终结果，操作后用 `ls` 确认。

```bash
rm -i backup/day1.txt   # 删除文件前确认
rmdir backup           # 只删除空目录
```

**`rm` 删除的内容通常不会进入桌面回收站。** 删除非空目录要用 `-r`，练习时可以用 `rm -ri 目录名` 逐项确认。删除前先看 `pwd` 和目标内容，尤其要检查通配符展开后会匹配哪些文件。

## 四、查看和编辑文本

| 需求 | 命令示例 | 记忆点 |
| --- | --- | --- |
| 查看短文本 | `cat notes/linux.txt` | 一次输出全部内容 |
| 分页阅读 | `less app.log` | `/关键词` 搜索，`n` 下一个，`q` 退出 |
| 查看开头 | `head -n 20 app.log` | 前 20 行 |
| 查看末尾 | `tail -n 30 app.log` | 后 30 行 |
| 跟随日志追加 | `tail -f app.log` | `Ctrl + C` 停止跟随 |
| 编辑文件 | `nano notes/linux.txt` | 常用 `Ctrl + O` 保存、回车确认、`Ctrl + X` 退出 |

Vim 先记住最小操作：`vim 文件名` 打开，按 `i` 输入，按 `Esc` 返回普通模式，再输入 `:wq` 保存退出；`:q!` 放弃未保存的修改。图片、压缩包等二进制文件不要用 `cat` 阅读。

## 五、把命令组合起来

管道 `|` 把前一条命令的标准输出交给后一条命令。重定向则改变输入或输出的位置；`>` 会覆盖文件，`>>` 会追加。下面的示例可以在前面的练习目录中运行：

```bash
printf 'INFO ready\nERROR missing file\n' > app.log
grep -n 'ERROR' app.log           # 查找匹配行并显示行号
grep 'ERROR' app.log | wc -l      # 统计匹配的行数
sed 's/ERROR/WARN/g' app.log      # 输出替换结果，默认不修改原文件
printf 'INFO finished\n' >> app.log
cat app.log | tee app-copy.log   # 同时显示并保存标准输出
```

常用符号的区别：

| 写法 | 含义 |
| --- | --- |
| `*.log` | 文件名通配符，通常由 Shell 展开；默认不匹配隐藏文件 |
| `?` | 文件名通配符，匹配一个字符 |
| `命令 < input.txt` | 从文件读取标准输入 |
| `命令 > output.txt` | 标准输出覆盖写入文件 |
| `命令 2> error.log` | 标准错误写入文件 |
| `命令 > run.log 2>&1` | 标准输出和标准错误写入同一文件，顺序有意义 |
| `命令一 && 命令二` | 第一条成功后才执行第二条 |
| `命令一 \|\| 命令二` | 第一条失败后才执行第二条 |
| `命令一; 命令二` | 第一条结束后继续执行第二条，不要求成功 |

Bash 变量赋值时等号两侧不加空格。双引号保留变量展开，单引号保留字面内容；路径可能包含空格时，使用引号包住。

```bash
topic='Linux notes'
echo "$topic"       # 输出 Linux notes
echo '$topic'       # 输出字面内容 $topic
mkdir -p "my notes"
```

语法细节可查 [Ubuntu 的 Bash 手册](https://manpages.ubuntu.com/manpages/noble/man1/bash.1.html)。

## 六、用户和权限：报错时先看原因

```bash
whoami              # 当前用户名
id                  # 用户及所属组的信息
groups              # 所属组
ls -l notes/linux.txt
```

例如 `-rw-r--r--`：首位 `-` 表示普通文件，后面三组分别是所有者、所属组和其他用户的权限。`r` 是读，`w` 是写，`x` 是执行；对应数字为 `4`、`2`、`1`，每组相加得到数字权限。

```bash
chmod 644 notes/linux.txt   # 所有者可读写，其余用户只读
chmod u+x run.sh            # 假设脚本已存在，给所有者增加执行权限
./run.sh                   # 通过路径运行脚本
```

目录的 `x` 表示可以进入、访问其中的已知名称，`r` 用于列出目录项；创建和删除目录项通常需要父目录的 `w` 和 `x`。文件能否删除，不能只看文件自身有没有写权限。

`sudo 命令` 用于按授权以其他身份执行命令，默认通常是 root。`su - 用户名` 切换登录身份，`passwd` 修改密码，`chown` 修改所有者或所属组。遇到 `Permission denied` 时，先确认用户、路径和权限，再判断是否需要管理员权限。

## 七、用 apt 安装和管理软件

Ubuntu 中，`update` 刷新软件索引，`upgrade` 才是升级已安装软件。这两个名字容易混淆。

```bash
sudo apt update
apt search tmux                 # 搜索软件包
sudo apt install tmux curl      # 安装软件及所需依赖
apt list --installed            # 查看已安装软件包
sudo apt upgrade                # 升级，先阅读待执行的变更
```

卸载用 `sudo apt remove 包名`；`purge` 还会清除软件包管理的配置，但不会替你删除家目录中的个人数据。`sudo apt autoremove` 清理不再需要的自动安装依赖，执行前检查列表。详见 [apt 手册](https://manpages.ubuntu.com/manpages/noble/man8/apt.8.html)。

## 八、SSH 登录与文件传输

以下命令在**本地电脑的终端**执行。示例中的用户名、地址、端口都需要换成实际值，远程机器也需要运行 SSH 服务并允许连接。

```bash
ssh -p 2222 student@192.0.2.10
```

登录后输入的命令运行在远程主机上，`exit` 退出远程 Shell。首次连接时，应通过可信渠道核对主机密钥指纹，再接受连接。具体参数见 [OpenSSH 的 ssh 手册](https://man.openbsd.org/ssh)。

传文件时回到本地终端，按“来源 → 目标”的顺序写路径：

```bash
# 上传本地文件，目标目录需要已经存在
scp -P 2222 ./notes.txt student@192.0.2.10:/home/student/

# 下载远程文件到本地当前目录
scp -P 2222 student@192.0.2.10:/home/student/result.txt ./

# 上传目录
scp -r -P 2222 ./notes student@192.0.2.10:/home/student/
```

注意：**`ssh` 指定端口用小写 `-p`，`scp` 用大写 `-P`**。参见 [scp 手册](https://man.openbsd.org/scp)。

## 九、下载、压缩和链接

下载先认识 `wget` 和 `curl`，需要多连接下载时再查 `aria2c`。示例 URL 需要换成实际下载地址：

```bash
wget -O package.tar.gz 'https://example.com/package.tar.gz'
curl -fL -o package.tar.gz 'https://example.com/package.tar.gz'
```

打包、查看包内容、解压可以这样串起来：

```bash
tar -czf notes.tar.gz notes/
tar -tzf notes.tar.gz
mkdir -p extracted
tar -xzf notes.tar.gz -C extracted/
```

`c` 创建，`x` 解包，`t` 列出内容，`z` 使用 gzip，`f` 后面指定归档文件。解压到单独目录更方便检查结果。ZIP 文件常用 `zip -r` 和 `unzip`，其他格式也可以查 `7z`。参数见 [tar 手册](https://manpages.ubuntu.com/manpages/noble/man1/tar.1.html)。

链接则用于让一个文件有另一个访问入口：

```bash
ln -s "$HOME/linux-practice/notes" "$HOME/notes-link"
ln app.log app-hard.log
```

符号链接记录目标路径，可指向目录、跨文件系统，但目标移动后可能失效；硬链接是同一文件的另一个名称，通常不能跨文件系统，也不能给目录创建。符号链接本身不会搬运数据。

## 十、后台运行与 tmux

`命令 &` 让命令在后台运行；`jobs` 查看当前 Shell 的作业，`fg` 恢复到前台。`Ctrl + Z` 会暂停前台作业，之后可用 `bg` 让它在后台继续。

**放到后台不等于断开 SSH 后还能继续。** 对需要回到现场查看的长任务，可以使用 tmux：

```bash
tmux new -s study        # 创建并进入 study 会话
# 在会话里运行自己的任务
```

离开会话时，先按 `Ctrl + B`，松开后再按 `D`。重新登录后：

```bash
tmux ls
tmux attach -t study
```

tmux 会话可以在终端断开后保留，但不能跨主机重启恢复任务。只需独立后台运行时，也可以了解 `nohup 命令 > run.log 2>&1 &`；需要开机启动或崩溃重启时，再学习系统服务。参考 [tmux 手册](https://manpages.ubuntu.com/manpages/noble/man1/tmux.1.html)。

## 十一、程序慢、磁盘满时怎么查

| 想知道什么 | 先用什么 |
| --- | --- |
| 哪个进程占用 CPU 或内存 | `top`，或安装后使用 `htop` |
| 整个文件系统还剩多少空间 | `df -h` |
| 当前目录占了多少空间 | `du -sh .` |
| 有哪些磁盘、分区和挂载点 | `lsblk -f` |
| 哪些进程在读写磁盘 | `iotop`，可能需要安装和提权 |
| 网卡和 IP 地址 | `ip addr`，旧教程也常用 `ifconfig` |
| 网络流量 | `iftop`、`nload`，可能需要安装 |
| 内核信息 | `uname -a` |
| 发行版信息 | `cat /etc/os-release` |
| 两个文本文件的差异 | `diff -u old.txt new.txt` |

停止进程前确认 PID 和任务用途。`kill PID` 默认发送终止信号，让程序有机会清理退出；`kill -9 PID` 是强制终止。`pkill` 可以按名称等条件匹配，使用时要留意是否会影响多个进程。

磁盘挂载是把文件系统接到目录树上。先用 `lsblk -f` 确认设备，再学习 `mount 设备 挂载点` 和 `umount 挂载点`。挂载点原有内容会暂时被遮住；临时挂载通常不会在重启后自动恢复，长期挂载需要进一步了解 `/etc/fstab`。

## 十二、PATH 和 Bash 配置

直接输入命令名时，Bash 会按规则查找命令；查找外部程序时会使用 `PATH` 中的目录。当前目录通常不在其中，因此运行当前目录中的程序要写 `./程序名`。

```bash
echo "$PATH"
export PATH="$HOME/.local/bin:$PATH"
```

`export` 让变量被后续启动的子进程继承，不会修改已经运行的进程，也不会自动写入永久配置。`env` 可以查看环境变量。`LD_LIBRARY_PATH` 则与动态库查找有关，遇到具体软件需要时再配置。

常用别名和路径设置可以写进 `~/.bashrc`，例如：

```bash
alias ll='ls -lah'
export PATH="$HOME/.local/bin:$PATH"
```

修改后执行 `source ~/.bashrc`，让当前 Bash 重新读取配置。`.bashrc` 主要由交互式非登录 Bash 读取；登录 Shell、其他 Shell 和系统服务的配置入口可能不同。它本身会执行命令，所以只加载自己信任的配置。相关规则见 [Bash 手册](https://manpages.ubuntu.com/manpages/noble/man1/bash.1.html)。

## 十三、给自己的一组复习练习

在家目录中新建一个未使用过的练习目录，再执行下面的命令，把文件操作、筛选、重定向和打包连起来：

```bash
mkdir ~/linux-review
cd ~/linux-review
mkdir notes
printf 'Linux\nBash\nSSH\n' > notes/topics.txt
cp notes/topics.txt notes/topics-backup.txt
printf 'tmux\n' >> notes/topics.txt
grep -n 'SSH' notes/topics.txt
wc -l notes/topics.txt
diff -u notes/topics-backup.txt notes/topics.txt
tar -czf notes.tar.gz notes/
tar -tzf notes.tar.gz
```

检查结果：`grep` 应找到第 3 行的 SSH，`wc -l` 应为 4，`diff` 应显示新增的 tmux，压缩包里应包含两个文本文件。`diff` 发现差异时返回非零状态是正常行为。

接下来遇到实际需求时，再沿着这些关键词继续学：

| 需求 | 查询方向 |
| --- | --- |
| 程序开机启动、自动重启 | `systemd`、`systemctl` |
| 服务启动失败、系统异常 | `journalctl`、`dmesg` |
| 定时备份或执行脚本 | `cron`、`systemd timer`、`at` |
| 网络与端口排查 | `ip route`、`ping`、`ss`、`dig` |
| 配置防火墙 | `ufw`、`nftables` |
| SSH 密钥登录 | `ssh-keygen`、`authorized_keys` |
| 增量同步和备份 | `rsync` |
| 重复执行一组操作 | Bash 脚本、条件判断和循环 |

复习时优先回答三个问题：这条命令在哪台机器上运行？当前目录在哪里？它会读取或修改什么对象？把这三点想清楚，再查具体参数，命令就容易读懂了。
